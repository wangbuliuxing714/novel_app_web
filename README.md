# 小说生成应用 - Web版

这是一个基于Flutter Web构建的小说生成应用，使用AI技术帮助用户创建小说大纲和章节内容。

## 功能特点

- 小说大纲生成
- 章节内容生成
- 实时输出显示
- 数据本地保存
- 响应式设计，适配各种设备

## 技术栈

- Flutter Web
- Dart
- SQLite (本地数据存储)
- AI生成服务集成
